A Classic Theme with 27 reading skins. Select a skin in Appearance > Customize > Reading 皮肤. Native menus and widgets supply the drawers. Search stays at the lower left. No bookmarks feature, external service or required plugin.

== Installation ==
Upload reading-0.1.2.zip in Appearance > Themes > Add Theme. Activate Reading. Assign primary/topics/footer menus under Appearance > Menus. Add content to the optional widget areas in Appearance > Widgets. Empty areas are omitted. Set the homepage in Settings > Reading.
