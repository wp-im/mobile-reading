# Mobile Reading · Reading Classic Theme

A standalone WordPress Classic Theme with 27 selectable visual skins, a persistent left tool rail and native menu/widget drawers. Bookmarks are omitted; search stays at the lower left.

Demo: [wordpress.im/mobile-reading](https://wordpress.im/mobile-reading/) · Source and releases: [wp-im/mobile-reading](https://github.com/wp-im/mobile-reading)

## Installation

Install the `reading-0.1.2.zip` theme package, then activate **Reading**. Choose a skin in **Appearance → Customize → Reading 皮肤**. Assign the primary/topics/footer menu locations and any of the eight optional widget areas through WordPress. Empty areas are omitted. No required plugin or build step.

The visual references retain their original CSS, SVG drawings and embedded imagery. WordPress owns posts, pages, categories, archives, search, pagination, comments and site identity. MUJI layouts preserve their distinct markup instead of being flattened into one shell.

## Quick skin preview

Use the footer dropdown to switch immediately between all 27 skins on the current page. The preview URL carries the selected skin through same-site links and search; it does not change the site default. Without JavaScript, choose a skin and press the switch button.

## 0.1.1 review fixes

- Wide Classic Editor tables scroll inside the article instead of widening the page.
- Selected-reading totals derive from published WordPress posts.
- Reading-size preferences use each site's home URL, isolating same-origin Multisite paths.

## Validation and boundaries

Local WordPress 7.1.4 / PHP 8.4 and Playwright Chromium validation covers 27 skins, four viewport widths, native menus/widgets and core routes. Detailed review and release notes accompany the release. This is not a claim of Safari/Firefox, physical-device, full assistive-technology or WordPress.org approval.
